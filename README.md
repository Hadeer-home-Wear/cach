# HADEER ACCOUNTS

واجهة عربية RTL لإدارة حسابات العملاء والديون لعلامة HADEER.

## المميزات الموجودة في النسخة الأولية
- تسجيل دخول محلي أولي، مع إمكانية تغيير كلمة المرور من الإعدادات.
- إدارة العملاء وتعديل بياناتهم.
- تسجيل المبيعات الآجلة والدفعات الجزئية.
- كشف حساب وسجل للعمليات والرصيد بعد كل حركة.
- ملخص إجمالي الديون والتحصيل.
- رسائل واتساب جاهزة للعميل عبر wa.me.
- تجهيز نص إعلان بضاعة جديدة وتصدير قائمة أرقام العملاء CSV.
- نسخة احتياطية JSON وطباعة كشف الحساب.
- تصميم متجاوب للهاتف والكمبيوتر.

## تشغيل سريع
1. فك ضغط `HADEER_ACCOUNTS.zip`.
2. افتح `index.html` في المتصفح، أو ارفع الملفات إلى مستودع GitHub.
3. لتفعيل GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. كلمة المرور الأولية في هذه النسخة: `Hadeer1994`.
5. لتغييرها: سجّل الدخول → الإعدادات → غيّر كلمة المرور.

## مهم جدًا قبل الاستخدام الفعلي
هذه نسخة أولية تحفظ البيانات وكلمة المرور في `localStorage` على نفس المتصفح والجهاز. لذلك:
- البيانات لا تتزامن تلقائيًا بين جهازين، وقد تُفقد عند مسح بيانات المتصفح.
- شاشة الدخول هنا ليست حماية حقيقية لبيانات الموقع المنشور للعامة؛ لا ترفع بيانات عملاء حقيقية أو تستخدمها كنظام آمن قبل ربط تسجيل دخول خادمي وقاعدة بيانات مع سياسات وصول مناسبة.
- `supabase/schema.sql` مخطط قاعدة بيانات مبدئي فقط؛ لا يوجد اتصال سحابي في هذه النسخة.
- لا تضع مفاتيح Supabase السرية أو `service_role` في ملفات GitHub.
- واتساب العادي لا يسمح بإرسال إعلان جماعي تلقائي من الموقع. زر الإعلان يجهز CSV وروابط محادثات فردية؛ استخدم قائمة بث واتساب نفسها لإرسال البث، مع مراعاة موافقة العملاء وشروط واتساب.
- رقم الهاتف يجب إدخاله برمز الدولة المناسب حتى تعمل روابط `wa.me` بشكل صحيح (لمصر عادةً 20 ثم الرقم دون الصفر الأول).
